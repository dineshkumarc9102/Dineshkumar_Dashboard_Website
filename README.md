# 📊 Dashboard Website

Welcome to my Dashboard Website! 🚀 This project is designed to provide a centralized platform for managing and visualizing financial data through interactive dashboards and reports.

## 📌 What You'll Find Here

* 💰 **Salary Dashboard:** Track salary details, investments, and financial growth.
* 📬 **Post Office Dashboard:** Monitor post office savings and investment schemes.
* 📈 **Stock Dashboard:** Analyze stock portfolio performance and investment trends.
* 🔐 **Secure Authentication:** JWT-based login system for protected access.
* 📊 **Power BI Integration:** Interactive reports and analytics embedded directly into the application.

## 🛠 Tech Stack

### Frontend

* React.js
* Vite
* Tailwind CSS
* React Router DOM
* Lucide React

### Backend

* Node.js
* Express.js
* JWT Authentication
* dotenv
* CORS

### Analytics

* Microsoft Power BI Embedded
